# Mini Expense Tracker

A simple full-stack expense tracker built with React, Node.js, Express and MongoDB.

## Features

- Add expenses
- View expenses
- Filter by category
- Delete expenses
- Category-wise summary
- Grand total

## Tech Stack

- React
- Node.js
- Express
- MongoDB
- Mongoose

## Run Locally

### Backend
```bash
cd backend
npm install
npm run dev
